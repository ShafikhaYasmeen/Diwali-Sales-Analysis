# Diwali-Sales-Analysis
Exploratory Data Analysis on Diwali Sales Data using Python


## Project Overview
This project focuses on analyzing Diwali sales data to understand customer behavior, spending patterns, and key factors influencing sales during the festive season.

## Dataset
- Diwali Sales Data
- Contains customer demographics, purchase amount, product category, state, and order details

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
- Data cleaning (handling missing values and data types)
- Exploratory Data Analysis (EDA)
- Customer segmentation by gender, age group, and marital status
- State-wise and product category-wise sales analysis
- Visualization of insights using bar charts and count plots

## Key Insights
- Female customers contributed higher overall sales
- Customers aged 26–35 formed the most active purchasing group
- Uttar Pradesh, Maharashtra, and Karnataka generated the highest revenue
- Clothing and Food categories were top-selling during Diwali

## Conclusion
The analysis reveals clear customer trends and high-performing product categories, helping businesses optimize marketing and inventory planning during festive seasons.
